# Fentek Havacılık — İHA Uçuş Merkezi

Uygulamayı ana İHA klasöründeki **IHA_BASLAT.bat** veya bu klasördeki **BASLAT.bat** ile açın.

- Ana uygulama: `flight_pro.py` (Python 3.12).
- İlk bağımlılık kurulumu: `KUR.bat`.
- USB bağlantı aracı: `GERCEK_BAGLANTI.bat`.
- Simülasyon kontrolleri: `SIMULASYON_TESTI.bat`.
- [Birleştirilmiş kılavuz ve teknik notlar](belgeler/UYGULAMA_KILAVUZU_VE_NOTLAR.md).
- [Diğer belgeler ve sunumlar](../belgeler/README.md).

Önceki altı kılavuz/rapor dosyasının tam içerikleri birleştirilmiş belgeye aktarılmıştır. Test raporları geçmiş çalışmaları kaydeder; gerçek uçuş veya donanım doğrulaması anlamına gelmez.

Uygulamanın kullandığı kodlar, görseller ve bağlantı ayarları bu klasördedir. `vendor`, `assets` ve diğer uygulama dosyaları birlikte tutulmalıdır.
